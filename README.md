# 🧠 Customer Churn Prediction & CLV Analysis

This project predicts which customers are likely to churn, estimates their lifetime value (CLV), and segments them into actionable groups for retention.

## 🚀 Project Steps
1. Data Exploration & Visualization  
2. Churn Prediction (Logistic Regression)  
3. CLV Calculation  
4. Customer Segmentation by CLV & Churn Risk  
5. Visualization & Business Insights  

## 📊 Technologies Used
- Python (Pandas, Scikit-learn, Matplotlib, Seaborn)
- Google Colab
- Data Visualization & Machine Learning

## 💡 Insights
- Key churn drivers: satisfaction score, inactivity, support tickets  
- CLV reveals who your most valuable customers are  
- Combined segmentation highlights where to focus retention efforts



⭐ **Goal:** Help e-commerce businesses improve retention and maximize customer lifetime value.
